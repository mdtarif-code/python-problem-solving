# Python Problem-Solving Journey

This repository documents my journey of solving Python problems regularly to improve my programming and problem-solving skills.

I'm doing this mainly to strengthen my Python fundamentals and logical thinking as part of my journey toward Data Science.

## My Approach

I try to solve problems by myself first. Not every solution here is the most optimal or efficient solution, and some of my first attempts may contain mistakes or unnecessary steps.

That's part of the learning process.

I solve Python problems regularly, try to understand different approaches, learn from my mistakes, and gradually improve my problem-solving skills.

## Learning Without Shortcuts

For many problems, I intentionally avoid using built-in functions that could solve the problem directly.

The goal is to understand the logic behind the solution and practice concepts like:

* Loops and conditions
* Lists and arrays
* Dictionaries and sets
* Strings
* Algorithms and problem-solving techniques

Built-in functions are useful in real-world programming, but while practicing, I sometimes avoid them to better understand how things work.

## Goal

The goal is simple: **solve problems consistently, make mistakes, learn from them, and become better at solving problems independently.**
